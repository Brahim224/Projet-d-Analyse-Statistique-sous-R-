# 🎓 Projet d’Analyse Statistique sous R — Employabilité des Étudiants

## 📌 Présentation du projet

Ce projet a été réalisé dans le cadre d’une étude statistique sur l’employabilité des étudiants de l’ENSA Kénitra.

L’objectif principal est d’analyser les facteurs qui influencent l’insertion professionnelle des étudiants après leurs études, à travers une approche :

- 📊 Quantitative
- 🗣️ Qualitative
- 📈 Statistique

L’étude explore plusieurs dimensions :
- Qualité de la formation académique
- Soft skills et compétences techniques
- Expériences professionnelles et stages
- Réseautage professionnel
- Adéquation formation / marché de l’emploi
- Importance des formations pratiques

---

# 🧠 Objectifs du projet

- Réaliser une enquête statistique sur l’employabilité des étudiants
- Analyser les données collectées avec R
- Tester plusieurs hypothèses statistiques
- Étudier les perceptions des étudiants
- Identifier les facteurs clés favorisant l’insertion professionnelle

---

# 🔬 Analyses statistiques réalisées

Le projet comprend :

✅ Analyse descriptive  
✅ Alpha de Cronbach (fiabilité du questionnaire)  
✅ Test du Khi-deux  
✅ Test de normalité de Shapiro-Wilk  
✅ Analyse qualitative thématique  
✅ Calcul de saturation sémantique (92,9%)  
✅ Visualisation des données

---

# 📊 Résultats principaux

- Saturation sémantique obtenue : **92,9%**
- Dépendance statistiquement significative entre :
  - Formation académique et employabilité
  - Soft skills et insertion professionnelle
  - Réseau professionnel et employabilité
  - Formation pratique et accès à l’emploi
